# create

下载并安装指定的浏览器。

## 用法

```bash
pbvm create [-b <browser>] [-i <buildId>] [-a <alias>] [-s]
```

## 选项

| 选项         | 简写 | 说明                                          |
| ------------ | ---- | --------------------------------------------- |
| `--browser`  | `-b` | 浏览器名称：`chrome`、`chromium`、`firefox`   |
| `--build-id` | `-i` | 浏览器版本号，格式因浏览器而异                |
| `--alias`    | `-a` | 浏览器别名，用于简化后续操作                  |
| `--store`    | `-s` | 仅下载到全局 Store，不写入 `browserlist.json` |

## buildId 格式

| 浏览器   | buildId 格式            | 示例             |
| -------- | ----------------------- | ---------------- |
| chrome   | `x.x.x.x`（四段版本号） | `134.0.6998.35`  |
| chromium | 纯数字 revision 号      | `1435764`        |
| firefox  | `channel_version`       | `stable_136.0.0` |

## 示例

### 交互模式

不带参数运行，按提示逐步选择：

```bash
pbvm create
```

交互流程：

1. 选择浏览器类型（chrome / chromium / firefox）
2. 输入对应的 buildId
3. 输入别名（可选，留空则自动生成）
4. 确认后开始下载安装

### 命令行模式

```bash
# 安装 Chrome 并设置别名
pbvm create -b chrome -i 134.0.6998.35 -a my-chrome

# 安装 Chromium（仅保存到 Store，不写入项目清单）
pbvm create -b chromium -i 1435764 -s

# 安装 Firefox
pbvm create -b firefox -i stable_136.0.0
```

## 行为说明

- 安装前会自动检查全局 Store 中是否已有相同浏览器，若有则跳过下载
- 安装成功后，默认将浏览器记录到当前目录的 `browserlist.json`
- 使用 `-s` 参数只下载二进制文件到全局缓存，不做项目关联
- 安装中断或失败时，已下载的不完整文件会被自动清理
