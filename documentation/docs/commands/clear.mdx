# clear

删除指定浏览器的 profile 目录，清除用户数据。

## 用法

```bash
pbvm clear [-t <target>]
```

## 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--target` | `-t` | 浏览器标识：`{browser}@{buildId}` |

## 会清除的内容

- Cookies
- 收藏夹
- 浏览历史
- 偏好设置
- 系统信任证书
- 其他用户数据

## 不会影响的内容

- 浏览器二进制文件（Store 缓存）
- `browserlist.json` 中的记录

## 示例

```bash
# 清除指定浏览器的 profile
pbvm clear -t chrome@134.0.6998.35

# 交互模式
pbvm clear
```

## 使用场景

- 浏览器出现异常行为，需要恢复到干净状态
- 自动化测试中需要清除上一次的会话状态
- 清除登录信息、cookies 等敏感数据

如需同时删除浏览器二进制文件，请使用 [`remove`](./remove) 命令。
