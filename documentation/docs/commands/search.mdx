# search

查询远程资源是否存在，检测目标浏览器是否可下载。

## 用法

```bash
pbvm search [-b <browser>] [-i <buildId>]
```

## 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--browser` | `-b` | 浏览器名称：`chrome`、`chromium`、`firefox` |
| `--build-id` | `-i` | 浏览器版本号 |

## 输出信息

### Browser info（本地状态）

| 字段 | 说明 |
|------|------|
| `platform` | 当前平台 |
| `browser` | 浏览器名称 |
| `buildId` | 版本号 |
| `installed` | 是否已安装到本地 Store |

### Search info（远程状态）

| 字段 | 说明 |
|------|------|
| `exists` | 远程资源是否存在 |
| `url` | 下载地址 |
| `status` | HTTP 响应状态码 |
| `redirected` | 是否发生了重定向 |
| `size` | 文件大小（字节） |
| `contentType` | 内容类型 |
| `lastModified` | 远程文件最后修改时间 |
| `etag` | 资源 ETag |
| `acceptRanges` | 是否支持断点续传 |

## 示例

```bash
# 查询 Chrome 指定版本
pbvm search -b chrome -i 134.0.6998.35

# 查询 Chromium revision
pbvm search -b chromium -i 1435764

# 交互模式
pbvm search
```

## 典型用途

- **验证版本号**：在 `create` 前确认 buildId 有效
- **检查可用性**：确认远程 CDN 是否可访问
- **获取文件大小**：预估下载所需时间和空间
