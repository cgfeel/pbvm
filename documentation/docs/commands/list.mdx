# ls / store

列出已安装的浏览器。

## 用法

```bash
# 列出项目关联的浏览器
pbvm ls [-a]

# 列出全局 Store 中的浏览器
pbvm store [-a]
```

## 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--all` | `-a` | 显示所有平台的浏览器，而非仅当前平台 |

## 说明

### `pbvm ls`

列出当前目录 `browserlist.json` 中记录的浏览器。按平台分组显示，当前平台优先展示。

输出格式：

```
mac_arm (current):

  my-chrome    →  revision: chrome@134.0.6998.35
  dev-firefox  →  revision: firefox@stable_136.0.0
```

### `pbvm store`

列出全局 Store 中已安装的所有浏览器（即已下载的二进制文件）。同样按平台分组。

## 示例

```bash
# 查看当前项目的浏览器
pbvm ls

# 查看所有平台的浏览器
pbvm ls -a

# 查看全局缓存中的所有浏览器
pbvm store

# 查看全局缓存中所有平台的浏览器
pbvm store -a
```

## 区分 ls 与 store

|            | `pbvm ls`                     | `pbvm store`                |
|------------|-------------------------------|-----------------------------|
| 数据来源    | `browserlist.json`（项目级）   | 全局缓存目录（系统级）         |
| 显示内容    | 项目关联的浏览器                | 已下载的所有浏览器二进制        |
| 包含别名    | 是                            | 否                           |
| 用途        | 查看项目用到哪些浏览器           | 查看本地缓存了哪些浏览器        |
